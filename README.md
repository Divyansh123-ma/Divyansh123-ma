# RRB ALP भर्ती 2026 — सूचना पोर्टल

यह वेबसाइट हिंदुस्तान अखबार में प्रकाशित **रेलवे भर्ती बोर्ड (RRB) - सहायक लोको पायलट (ALP)** के 11,127 पदों की भर्ती अधिसूचना के आधार पर बनाई गई है।

## 📋 वेबसाइट की विशेषताएं

- 🏠 **होम पेज (`index.html`)** — हीरो सेक्शन, मुख्य बिंदु, पात्रता, चयन प्रक्रिया, समय-सारणी, लाइव काउंटडाउन
- 📝 **आवेदन प्रक्रिया (`apply.html`)** — स्टेप बाय स्टेप गाइड, शुल्क तालिका, चेकलिस्ट
- 📚 **चयन व सिलेबस (`syllabus.html`)** — CBT-1, CBT-2, CBAT का विस्तृत पैटर्न + सिलेबस + वेतन
- 📰 **समाचार (`news.html`)** — मुख्य खबर + सेक्शन कंट्रोलर साइको स्थगन की खबर
- ❓ **FAQ व संपर्क (`faq.html`)** — 12 अक्सर पूछे जाने वाले प्रश्न + संपर्क फॉर्म

## 🚀 कैसे चलाएं

कोई बिल्ड स्टेप नहीं है — यह शुद्ध HTML/CSS/JS है।

```bash
# किसी भी स्टैटिक सर्वर से चलाएं
python3 -m http.server 8000
# फिर ब्राउज़र में http://localhost:8000 खोलें
```

या `index.html` को सीधे ब्राउज़र में खोलें।

## 🎨 तकनीकी स्टैक

- **HTML5** — सेमांटिक मार्कअप
- **CSS3** — कस्टम डिज़ाइन सिस्टम, CSS Variables, Grid, Flexbox, रिस्पॉन्सिव
- **Vanilla JavaScript** — काउंटडाउन, FAQ अकॉर्डियन, मोबाइल मेन्यू, स्क्रॉल रिवील
- **Google Fonts** — Noto Sans Devanagari + Poppins
