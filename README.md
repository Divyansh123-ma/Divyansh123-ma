# RRB ALP भर्ती 2026 — सूचना पोर्टल (Single Page)

यह वेबसाइट हिंदुस्तान अखबार में प्रकाशित **रेलवे भर्ती बोर्ड (RRB) - सहायक लोको पायलट (ALP)** के 11,127 पदों की भर्ती अधिसूचना के आधार पर बनाई गई एक **सिंगल-पेज वेबसाइट** है। सभी सेक्शन एक ही `index.html` में हैं और स्मूथ स्क्रॉल नेविगेशन से जुड़े हैं।

## 📋 वेबसाइट के सेक्शन

सभी कंटेंट एक ही पेज पर — स्मूथ स्क्रॉल navigation:

- 🏠 **`#home`** — हीरो सेक्शन + लाइव काउंटडाउन (14 जून तक)
- 📊 **`#highlights`** — मुख्य बिंदु, टाइमलाइन, पात्रता
- 📝 **`#apply`** — 6-चरण आवेदन गाइड + शुल्क तालिका + चेकलिस्ट
- 📚 **`#syllabus`** — CBT-1, CBT-2, CBAT पैटर्न + सिलेबस + वेतन
- 📰 **`#news`** — मुख्य खबर + सेक्शन कंट्रोलर साइको स्थगन
- ❓ **`#faq`** — 12 अक्सर पूछे जाने वाले प्रश्न
- 📞 **`#contact`** — संपर्क जानकारी + संदेश फॉर्म
